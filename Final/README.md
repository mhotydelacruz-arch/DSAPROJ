# GARDEN SIMULATOR
A Simulation that use Data Structures and Algorithms in every farming function

# Created By:
- Ehrnell Dela Cruz

# Details:
A Simutaion Game that player can Farm and Sell Crops to village, this project was almost based on the Global Market of the corps such as Vegetables, Fruits and Meat and Poultry, on the DSA Part all of the Features was based on the Topics that tackled for the Whole Semester.

# How To Play:
- As the User see you can do the Basic Farm Functions
- You can buy the supplies on the market sections
- Choose the plants you want to plant
- to unlock the features you need an "Insight"
- to gain insight you need to do Farming
- you can sell the crops and poultry on the Village Orders section to gain coins

#Additonal Topics:
- Graphs, Adjacency Lists/ Matrices, DFS/BFS
- Linear vs. Binary Search
- Djikstra's Algorithm and Greedy Patterns
- Dp Memoization, Divide and Conquer
