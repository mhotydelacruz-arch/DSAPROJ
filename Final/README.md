# GARDEN SIMULATOR
# A Simulation that use Data Structures and Algorithms in every farming function

# Details:
A Simutaion Game that player can Farm and Sell Crops to village, this project was almost based on the Global Market of the corps such as Vegetables, Fruits and Meat and Poultry, on the DSA Part all of the Features was based on the Topics that tackled for the Whole Semester.
